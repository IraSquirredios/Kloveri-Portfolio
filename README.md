# Портфолио Cloveri Start / Cloveri Start Portfolio

Каталог продуктов Cloveri Start из GitLab.

- `portfolio/portfolio_frontend/` — актуальный React/TypeScript интерфейс.
- `portfolio/src/` — предыдущая версия интерфейса.
- `platform/` — Python-сервис.

[Инструкция запуска](portfolio/portfolio_frontend/README.md). [Настройка публикации](portfolio/deploy/README.md).

Для полноценной работы нужен доступ к внешним сервисам и настройка окружения. Локальные env-файлы, зависимости и история Git исключены; шаблоны настроек сохранены.

## Самостоятельная версия

Локальный API на Python и SQLite находится в `standalone/server.py`. Актуальный React-интерфейс подключён к нему. Внешние сервисы Cloveri для этого режима не нужны.

### Запуск через Docker

```sh
docker compose up --build
```

Откройте http://localhost:8080. Нажмите «Создать аккаунт», укажите email и пароль от 8 символов. Для каждого нового пользователя создаются три примерных продукта. Можно добавлять, редактировать, удалять продукты и менять публикацию. Данные разных пользователей изолированы, база хранится в Docker volume. Токен хранится только в памяти вкладки; после обновления страницы требуется повторный вход.

### Запуск без Docker

Терминал 1 из корня проекта:

```sh
cd standalone
python3 server.py
```

Терминал 2 из корня проекта:

```sh
cd portfolio/portfolio_frontend
npm ci
npm run dev
```

Откройте http://127.0.0.1:3003. Vite направляет `/api` на локальный порт 8000.

### Проверки и ограничения

API проверен запросами: регистрация, вход, создание, изменение, удаление, публикация, запрет доступа к чужому продукту и выход. React production build проходит. В браузере проверены регистрация, вход, каталог, создание, редактирование и перевод в черновик. Docker Compose пока не проверен: Docker на машине отсутствует. Это локальная портфолио-версия; перед публичным размещением нужны HTTPS, ограничения частоты входа, резервное копирование и отдельная проверка безопасности.

Проверка API без сторонних зависимостей: `python3 tests/test_api.py` из корня проекта.
